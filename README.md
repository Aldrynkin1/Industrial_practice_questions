# Практикум по C#

Консольное приложение с заданиями уровней 1–3. Для запуска требуется .NET 10 SDK:

```bash
dotnet run
```

В главном меню выберите уровень, затем номер задания. `b` возвращает к выбору уровня; `0` или `q` завершает приложение. Todo List сохраняет данные в `tasks.json` в текущем каталоге.

## Статус заданий

| № | Задание | Статус |
|---:|---|---|
| 1–14 | Базовый уровень | Выполнено |
| 15 | Основы Git | Не входит в этот объём |
| 16–34 | Средний уровень | Выполнено |
| 35 | Git: PR, Conventional Commits и rebase | Инструкция в приложении; требуется удалённый репозиторий |
| 36–45 | Продвинутый уровень: C#, JSON и unit-тесты | Выполнено |
| 46–50 | Продвинутый уровень: Git | Учебные инструкции доступны в приложении; команды выполняются в отдельной учебной ветке/репозитории |

Для запуска unit-тестов библиотеки:

```bash
dotnet test Tests/CSharpPracticum.Tests.csproj
```

## Практикум по базам данных

Отдельное решение практикума по Microsoft SQL Server находится в [`database/`](./database/):

- [`init.sql`](./database/init.sql) пересоздаёт учебную базу `PracticeDB` и загружает тестовые данные.
- [`sql-notes.md`](./database/sql-notes.md) содержит SQL-запросы и ожидаемые результаты заданий 1–27.
- [`DatabaseIntegration/`](./database/DatabaseIntegration/) — отдельное C#-приложение для заданий 28–30.

Для C#-заданий задайте строку подключения в переменной окружения `PRACTICE_DB_CONNECTION`. Не помещайте её в исходный код или файлы репозитория.

Порядок публикации проекта: [инструкция по Git](./Порядок%20публикации%20в%20Git.md).
