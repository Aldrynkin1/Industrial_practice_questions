# Практикум по C#

Консольное приложение с решениями заданий 1–14 и 16–34, а также чек-листом задания 35. Для запуска требуется .NET 10 SDK:

```bash
dotnet run
```

В главном меню выберите уровень, затем номер задания. Для уровня 2 используйте номера 16–35. `b` возвращает к выбору уровня; `0` или `q` завершает приложение.

## Практикум по базам данных

Отдельное решение практикума по Microsoft SQL Server находится в [`database/`](./database/):

- [`init.sql`](./database/init.sql) пересоздаёт учебную базу `PracticeDB` и загружает тестовые данные.
- [`sql-notes.md`](./database/sql-notes.md) содержит SQL-запросы и ожидаемые результаты заданий 1–27.
- [`DatabaseIntegration/`](./database/DatabaseIntegration/) — отдельное C#-приложение для заданий 28–30.

Для C#-заданий задайте строку подключения в переменной окружения `PRACTICE_DB_CONNECTION`. Не помещайте её в исходный код или файлы репозитория. В практикуме подробно расписаны задания 1–10; для заданий 11–30 указаны темы.
